# Human two-person agreement round (Cohen's κ)

Same 50 bugs / 178 files as the AI round (`../v2/`), ruleset 0.2.0, protocol
rev. 2.1 (`docs/ANNOTATION_PROTOCOL.md`). Everything is done in Excel.

| Path | What |
|---|---|
| `handout/annotation_A.xlsx` | workbook for annotator A |
| `handout/annotation_B.xlsx` | workbook for annotator B (identical, no answers) |
| `returned/` | put the two filled workbooks here, file names unchanged |
| after import: `{bugs,files}_annotator_{A,B}.csv`, `steps_{A,B}.md`, `agreement_report.md`, `disagreements.csv` | written by the import step |

Each workbook has: `Start here` (instructions), `1_files` (178 rows),
`2_bugs` (50 rows), `log` (time and ambiguities), and look-up copies of the
protocol's Appendices A–C and worked cases. Yellow cells are answers; grey
cells are given. Drop-down lists hold the allowed values.

## Steps

1. Give each annotator **only** their workbook plus `docs/ANNOTATION_PROTOCOL.md`
   and `docs/CLASSIFICATION_RULES.md` (and `docs/GLOSSARY.md`). Not the
   `key_*.csv` files, not the other workbook.
2. Each annotator works alone (2–3 hours): sheet `1_files` first, then
   `2_bugs`, then `log`. No discussion of cases until both have returned.
3. Save both filled workbooks into `returned/` (names unchanged:
   `annotation_A.xlsx`, `annotation_B.xlsx`).
4. Run

       python Scripts/annotation_workbook.py import

   It checks that every answer is filled with an allowed value (and lists any
   gaps, by row), converts the workbooks to CSV, and computes Cohen's κ for
   A vs B and each vs the frozen ruleset → `agreement_report.md`,
   `disagreements.csv`.
5. Pass: κ ≥ 0.80 (A vs B) on the bug `label` and the file `counts` decision.
   Each disagreement is classified (training / evaluation / annotator slip,
   protocol §4). A disagreement that reveals an unclear rule is resolved by
   amending the rule and bumping the ruleset version, never by choosing an
   answer for a single case.
6. The κ values and the resolution go into the paper (§3.3 and Threats).

The workbooks were generated by `python Scripts/annotation_workbook.py make --names A B`.
The pipeline was tested by filling the workbooks with the AI round's answers,
which reproduced that round's report exactly.
